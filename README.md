## ◈ SOBRE O MIKASA

O **MIKASA V8** é um projeto de automação para WhatsApp que reúne código, ferramentas e scripts de inicialização em uma estrutura desenvolvida para evoluir continuamente.

A proposta é oferecer uma experiência prática de instalação e execução, com acesso ao código-fonte e possibilidade de utilização em ambientes compatíveis.

## 🚀 INSTALAÇÃO EXPRESSA

<div align="center">

### UM COMANDO. UMA INSTALAÇÃO. MIKASA V8.

Copie o bloco completo abaixo e cole no terminal do Termux.

</div>

```bash
pkg update -y && pkg install -y git nodejs-lts bash && git clone https://github.com/DOCTOR-VALEYARD/mikasa-v8.js.git && cd mikasa-v8.js/mikasa-bot && bash instalar.sh && npm install dotenv && bash iniciar.sh
```

<details>
<summary><b>📋 O que o comando executa?</b></summary>

1. Atualiza a lista de pacotes do Termux.
2. Instala Git, Node.js LTS e Bash.
3. Baixa o repositório oficial do MIKASA V8.
4. Entra no diretório `mikasa-bot`.
5. Executa o instalador `instalar.sh`.
6. Instala `dotenv`, dependência que pode estar ausente.
7. Executa `iniciar.sh`.

**Observação:** o comando é destinado a uma instalação nova. Se a pasta do repositório já existir, o `git clone` não será executado com sucesso. O projeto também precisa conter os scripts nos caminhos indicados.

</details>

## ▶️ INICIALIZAÇÃO

Após a instalação, utilize o comando abaixo para iniciar o bot novamente:

```bash
cd ~/mikasa-v8.js/mikasa-bot && bash iniciar.sh
```

Na primeira conexão, siga as instruções exibidas no terminal para realizar o pareamento do WhatsApp.

## 🖥️ COMPATIBILIDADE COM HOSPEDAGENS

O projeto pode ser executado em hospedagens Linux que ofereçam as ferramentas e permissões necessárias.

Requisitos gerais:

- Node.js em versão compatível.
- npm.
- Git e Bash, quando os scripts forem utilizados.
- Dependências do projeto instaladas.
- Configurações e credenciais fornecidas de forma segura.

Em plataformas com painel de hospedagem, utilize o comando de inicialização recomendado pelo provedor. Nem todos os serviços permitem executar scripts Bash diretamente.
